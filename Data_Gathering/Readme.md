> There are four major python libraries for gathering data: wbdata, faostat, eurostat, yfinance. Each library has its own strengths and weaknesses, and the choice of which one to use depends on the specific needs of the project.
- **wbdata:** This library is a wrapper for the World Bank's data API. It provides access to a wide range of economic and social data, including indicators such as GDP, population, and education. It is easy to use and has good documentation, but it may not have as much data as some of the other libraries.
- **faostat:** This library is a wrapper for the Food and Agriculture Organization's data API. It provides access to a wide range of data on agriculture, including production, trade, and prices. It is also easy to use and has good documentation, but it may not have as much data as some of the other libraries.
- **eurostat:** This library is a wrapper for the European Union's statistical office data API. It provides access to a wide range of data on the European Union, including economic, social, and environmental data. It is also easy to use and has good documentation, but it may not have as much data as some of the other libraries.
- **yfinance:** This library is a wrapper for Yahoo Finance's data API. It provides access to a wide range of financial data, including stock prices, historical data, and financial news. It is also easy to use and has good documentation, but it may not have as much data as some of the other libraries.                            
  
  Overall, the choice of which library to use depends on the specific needs of the project and the type of data that is required. It may be necessary to use multiple libraries to gather all of the necessary data for a project.
